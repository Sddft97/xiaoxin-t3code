# 参与星尘 Agent / Contributing to Stardust Agent

先在[星尘 Issues](https://github.com/zds-xiaoxin/stardust/issues)搜索已有反馈。新问题可用错误反馈或功能建议模板，中文和英文都可以。

Fork [zds-xiaoxin/stardust](https://github.com/zds-xiaoxin/stardust)，在你的 fork 中从 `main` 创建分支。提交 PR 时选择 `zds-xiaoxin/stardust` 为目标仓库，目标分支为 `main`。写明改动、验证命令和测试结果。涉及界面时附上脱敏截图。

Search [Stardust Issues](https://github.com/zds-xiaoxin/stardust/issues) for existing reports. Use the bug or feature template for new issues. Chinese and English are both welcome.

Fork [zds-xiaoxin/stardust](https://github.com/zds-xiaoxin/stardust) and branch from `main` in your fork. Open a pull request with `zds-xiaoxin/stardust` as the base repository and `main` as the base branch. Include a summary, verification commands, and results. Attach redacted screenshots for UI changes.
