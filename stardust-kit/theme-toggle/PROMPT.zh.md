# 把「主题开关」装进你的工作台

状态：**设计稿**。这就是本页导航栏右上角正在用的开关；仍是设计稿，应用里没有它。

直接把下面这段提示词发给 Claude Code / Codex / T3 Code：

```text
请参考 `stardust-kit/theme-toggle/demo.html`，给我的导航栏做一个深浅主题开关：
1. 36px、圆角 11px 的图标瓦片；深色主题显示紫色瓦片 + 暖白太阳，浅色主题显示深靛瓦片 + 淡紫月亮，两层颜色交叉淡入；
2. 太阳变月亮是同一个形状：核心圆放大并被一个偏移的圆切成月牙，光线旋转 -90° 缩小淡出，两颗小星淡入；用一个 0→1 的进度值驱动，时长 240ms；
3. 悬停上浮 1px 并加深彩色投影，按下缩到 0.92；键盘焦点是 2px 外环、间距 3px；
4. 触屏上点击热区扩到 44×44px，不撑高导航栏；
5. `aria-label` 描述点击后的动作（「切换到浅色 / 深色」），不要再加 `aria-pressed`；
6. `prefers-reduced-motion` 下直接切换，不做动画。
```
