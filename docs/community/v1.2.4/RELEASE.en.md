# Stardust Agent v1.2.4

- Updated the reasoning effort slider to the r5 galaxy animation and reduced rendering work in the sidebar, theme switcher, and command palette.
- Updated Stardust themes and branding. The composer and sidebar return to the C115 layout, with a thinner composer border.
- Codex tries to recover from supported ChatGPT-sharing errors while preserving the existing conversation.
- New temporary worktrees use the `stardust/` branch prefix. Existing branch names continue to work.
- Added a Windows x64 beta alongside the macOS Apple Silicon build. WSL and voice input are unavailable in the Windows beta.

Download the installer for your platform and check it against `SHA256SUMS.txt`. The Mac build is ad-hoc signed and is not notarized by Apple. If Windows shows SmartScreen, verify the download source and checksum before choosing **More info → Run anyway**. [Windows setup and checksum instructions](../../user/stardust-windows-install.md)
